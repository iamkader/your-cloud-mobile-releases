# Your Cloud — Application Android

**Your Cloud** est une plateforme de stockage et de gestion de fichiers dans le cloud, accessible depuis un navigateur web et une application mobile Android.

Cette application permet de retrouver, organiser, consulter et partager ses fichiers depuis son téléphone.

## Télécharger l'application

La dernière version Android est disponible dans les publications officielles du projet.

**[Télécharger Your Cloud pour Android](https://github.com/iamkader/your-cloud-mobile-releases/releases/latest)**

Les versions précédentes sont accessibles dans la section [Releases](https://github.com/iamkader/your-cloud-mobile-releases/releases).

## Installation sur Android

1. Téléchargez le fichier `.apk` correspondant à la dernière version.
2. Ouvrez le fichier téléchargé sur votre téléphone Android.
3. Autorisez l'installation depuis cette source si Android le demande.
4. Suivez les instructions à l'écran.
5. Lancez **Your Cloud** et connectez-vous à votre compte.

**Remarque :** l'application étant distribuée directement sous forme d'APK, Android peut demander une autorisation supplémentaire lors de son installation.

## Fonctionnalités

- **Gestion des fichiers** : consulter, organiser, renommer et supprimer ses fichiers et dossiers.
- **Téléversement** : envoyer des fichiers depuis son téléphone vers son espace cloud.
- **Prévisualisation** : consulter les images, PDF et autres formats pris en charge.
- **Partage** : partager ses fichiers avec d'autres personnes.
- **Authentification** : accéder à son compte de manière sécurisée, notamment avec Google.
- **Synchronisation** : retrouver ses fichiers entre l'application mobile et la plateforme web.

Certaines fonctionnalités peuvent évoluer selon les versions de l'application.

## Versions et mises à jour

Les versions sont publiées selon le format `vMAJEURE.MINEURE.CORRECTIF`, par exemple `v1.0.10`.

Chaque publication contient le fichier APK correspondant et peut inclure des notes décrivant les nouveautés, corrections et améliorations.

Pour effectuer une mise à jour, téléchargez la nouvelle version et installez-la sur votre appareil Android.
